**PassVault** — это лёгкий и автономный десктопный менеджер и генератор паролей с локальным шифрованием. Все данные хранятся исключительно на вашем устройстве в зашифрованном виде без передачи в облако или сторонние сервисы.

---

## ✨ Основные возможности

* **Генератор криптостойких паролей:**
  * Настройка длины пароля (от 8 до 32 символов) и состава алфавита (заглавные буквы, цифры, специальные символы).
  * Расчёт энтропии и визуальная оценка надёжности пароля в реальном времени.
* **Защищённое локальное хранилище:**
  * Поддержка выбора произвольного файла базы паролей (`.enc`) при входе.
  * Атомарное сохранение данных через временный файл для защиты базы от повреждения при сбое питания.
* **Удобное управление записями:**
  * Создание, удаление, поиск и мгновенная фильтрация карточек по названию, логину или категории.
  * Быстрая генерация пароля в один клик прямо при добавлении новой записи.
  * Резервный экспорт записей в формат JSON.
* **Продуманная безопасность и UX:**
  * **Автоочистка буфера обмена:** скопированный пароль автоматически стирается из буфера через 15 секунд.
  * Переключение между светлой и тёмной темами оформления.

## 🛡️ Криптография и безопасность

* **Алгоритм шифрования:** `AES-256-GCM` (аутентифицированное шифрование с проверкой целостности данных и защитой от подмены файла).
* **Формирование ключа (KDF):** `PBKDF2` с хэш-функцией `SHA-256` и **600 000 итерациями** на уникальной 128-битной криптографической соли для каждого сохранения.
* **Генерация случайных чисел:** используется криптографически стойкий генератор `System.Security.Cryptography.RandomNumberGenerator`.
* **Очистка памяти:** массивы с ключами шифрования и расшифрованными данными принудительно зануляются через `CryptographicOperations.ZeroMemory` сразу после использования.

## 🛠️ Стек технологий и архитектура

* **Платформа и язык:** .NET 10, C# 14
* **UI-фреймворк:** Avalonia UI (Fluent Theme)
* **Архитектура:** MVVM (`CommunityToolkit.Mvvm` с Source Generators)
* **Dependency Injection:** `Microsoft.Extensions.DependencyInjection`
* **Сериализация:** `System.Text.Json`
